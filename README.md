# Google reCAPTCHA v3

Stop bots on PeltyCMS forms with Google reCAPTCHA v3

Official captcha / bot protection for [PeltyCMS](https://github.com/MythicalLTD/PeltyCMS).

## Why this addon

Anyone tired of spam accounts and bot ticket floods.

## Features

- Protect login, register, tickets and checkout with **Google reCAPTCHA v3**
- Server-side verification inside the WASM captcha addon
- Site keys configured once in Pelty settings
- No theme PHP hacks

## How it works

1. Install **Google reCAPTCHA v3** from the [Mythical marketplace](https://market.mythicalsystems.org/marketplace/product/captcha-recaptcha-v3) inside Pelty Admin → Addons.
2. Open Pelty Admin → Settings, paste your Google reCAPTCHA v3 site + secret keys, and turn it on for login / register / tickets.
3. Customers hit checkout / login / order flow as usual — Google reCAPTCHA v3 runs in the background.

## Requirements

- PeltyCMS with WASM addons enabled
- Working Google reCAPTCHA v3 credentials
- Outbound HTTPS from your panel
